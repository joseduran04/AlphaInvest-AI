# AlphaInvest AI — Frontend

Frontend web de AlphaInvest AI, plataforma educativa orientada al análisis financiero, simulación de inversiones y apoyo inteligente para la toma de decisiones.

## Estado actual

El frontend se encuentra en fase inicial de desarrollo.

Backend estable de referencia:

- API: `v1.0.0`
- Base API: `/api/v1`
- Swagger: `/docs`
- ReDoc: `/redoc`
- OpenAPI: `/openapi.json`

El frontend debe consumir exclusivamente la API FastAPI. No debe conectarse directamente a PostgreSQL, Supabase ni MongoDB.

## Stack

- React 19
- TypeScript 6
- Vite 8
- Oxlint
- Prettier
- npm

La arquitectura del frontend será modular y orientada por funcionalidades.

## Requisitos

- Node.js 24 o una versión compatible con Vite 8
- npm

## Instalación

Desde el directorio `frontend`:

```bash
npm install
```
